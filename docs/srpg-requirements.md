# SRPG 要件定義書（個人開発テンプレート）

## 1. プロジェクト概要
- **目的**：ブラウザでプレイ可能なシングルプレイSRPGを制作する。
- **将来方針**：ストーリー型ゲームへ拡張可能な構成にする。
- **公開形式**：Webアプリ（PCブラウザ想定）。
- **リポジトリ**：GitHub または GitLab。
- **CI/CD**：コミット時の自動ビルド・自動デプロイを実施。

## 2. 技術スタック
- **バックエンド**：Java / Spring Boot
- **フロントエンド**：HTML / JavaScript または TypeScript
- **ゲーム描画ライブラリ**：未定（Phaser等を候補として検討）
- **データベース**：PostgreSQL / MySQL / SQLite（要決定）
- **ホスティング**：Render / Fly.io / VPS（要決定）

## 3. ゲーム基本仕様
- **プレイ形式**：シングルプレイ
- **ステージ数**：3〜5
- **ストーリー**：将来追加予定
- **セーブ方式**：ローカルまたはクラウド（要決定）

## 4. マップ仕様（パラメータ化）
- **マップサイズ**：設定ファイルまたはJSONで変更可能
- **地形**：初期は平地のみ
- **将来拡張**：森・高低差・地形効果
- **マップデータ形式**：JSON / YAML 等

## 5. ユニット仕様
- **味方ユニット数**：初期 5体
- **敵ユニット数**：ステージごとに設定可能
- **初期配置**：設定ファイルで指定
- **ユニットパラメータ**：HP / 攻撃 / 防御 / 移動力 / 射程

## 6. 行動仕様
- **1ターン行動**：移動 / 攻撃 / 待機
- **移動後攻撃**：可能
- **ターン制**：プレイヤーターン → 敵ターン

## 7. 戦闘計算
- **基本式**：`ダメージ = 攻撃 - 防御`
- **最低ダメージ**：1
- **将来拡張**：クリティカル・命中率

## 8. 成長システム
- ユニットはレベルアップ可能
- 経験値は敵撃破で取得
- レベルアップ時に確率でステータス上昇
- レベル上限は要決定

## 9. 敵AI
- **基本行動**：最寄りのプレイヤーユニットへ移動
- **攻撃条件**：攻撃可能なら攻撃
- **将来拡張**：ボスAI / 行動優先度

## 10. 勝敗条件
- **勝利条件**：敵全滅
- **敗北条件**：味方全滅
- **将来拡張**：防衛・ターン制限など

## 11. UI仕様
- **操作**：マウスクリック
- **画面構成**：タイトル / ステージ選択 / 戦闘画面 / 結果画面
- **将来拡張**：ストーリー画面

## 12. パラメータ設計（重要）
以下は外部設定ファイルから変更可能とする。
- マップサイズ
- 敵ユニット数
- 味方ユニット数
- 初期配置
- ユニットステータス
- AI設定

## 13. データフォーマット例（JSON）
```json
{
  "map": {"width": 10, "height": 10},
  "playerUnits": 5,
  "enemyUnits": 8,
  "enemySpawn": [[3, 4], [5, 6]]
}
```

## 14. 非機能要件
- **パフォーマンス**：通常ブラウザで快適に動作
- **セキュリティ**：基本的なAPI保護
- **ログ**：エラーログをサーバに保存

## 15. 将来拡張
- スマホ対応
- ストーリーイベント
- 新クラス追加
- 地形効果
